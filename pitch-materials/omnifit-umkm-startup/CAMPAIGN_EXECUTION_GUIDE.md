### Lead Scoring Matrix

```
SCORE CRITERIA:
───────────────

Company Size:
├─ 10-50 orang: +5 (good fit)
├─ 50-300 orang: +10 (excellent fit)
└─ 300+ orang: +5 (might prefer enterprise solution)

Industry:
├─ Tech/Startup: +10 (data-driven mindset)
├─ Retail/Manufacturing: +8 (practical)
├─ Services/Consulting: +7
└─ Other: +5

Engagement:
├─ Sign up, login <1 day: +5
├─ Run assessment: +10 (high intent)
├─ Invite team: +15 (very high intent)
├─ Zero activity: -5 (low intent)
└─ Contact support: +10

Email Engagement:
├─ Open rate >50%: +3
├─ Click rate >20%: +5
├─ Reply to email: +10

Budget Indicator:
├─ "Berapa harga?" asked: +8 (serious)
├─ Ask about payment terms: +10 (very serious)
├─ Ask about features, not price: +5

Decision Timeframe:
├─ "Mau mulai minggu depan": +15 (urgent)
├─ "Mau coba dulu": +8 (interested, not urgent)
├─ "Tunggu approval": +5 (might not happen)

LEAD SCORING TIERS:
───────────────────

HOT (Score 50+):
→ Action: Sales call ASAP (within 24 hours)
→ Offer: Free 15-min consultation + custom setup

WARM (Score 30-49):
→ Action: Email follow-up + offer demo
→ Offer: Product walkthrough, no pressure

COLD (Score 10-29):
→ Action: Email nurture sequence
→ Offer: Free resources, educational content

INACTIVE (Score <10):
→ Action: Quarterly check-in
→ Offer: Remind about trial, special offer if expired
```

## 📞 Sales Call Script (untuk HOT leads)

### Opening (2 min)
```
"Halo [Name], terima kasih sudah mau ngobrol. 
Saya lihat Anda sudah sign up ke Omnifit beberapa hari lalu.

Bagaimana first impression Anda? Sudah coba platform-nya?"

[Listen]

"Bagus, sebelum saya lanjut — biar saya understand 
situasi Anda lebih baik: Berapa jumlah tim Anda sekarang?"
```

### Discovery (3 min)
```
"Interesting. [Number] orang adalah growth stage yang bagus.

Saya pengin tanya: Apa tantangan terbesar Anda di HR/talent 
management sekarang? (recruitment, retention, performance management?)"

[Listen & take notes]

"Saya ngerti. Itu adalah masalah yang common di UMKM ukuran Anda."
```

### Problem Validation (2 min)
```
"Kalau saya understand benar, masalah utama Anda adalah:
[Reflect back their problem]

Itu correct?"

[If yes] "Bagus, itu exactly yang Omnifit solve."
[If no] "Oh, saya mistakenkan. Cerita lebih lanjut?"
```

### Solution Pitch (3 min)
```
"Omnifit solve ini dengan cara [explain relevant feature].

Specifically untuk kasus Anda:
- [Feature A] akan help dengan [their pain point A]
- [Feature B] akan solve [their pain point B]

Hasilnya: [Expected outcome]"
```

### Proof (1 min)
```
"Kami sudah help 50+ UMKM dengan situation similar. 
Example: PT Maju Bersama yang juga [similar pain point].
Mereka save [X% savings] dan got [clear benefit]."
```

### Objection Handling (2 min)
```
If they ask "Berapa harga?":
"Pricing simple: Rp 500K/month untuk Starter Plan (yang perfect 
untuk Anda sekarang). Unlimited assessment cycles.

Compare dengan konsultan: Rp 20M per project. 
Jadi Omnifit 80% lebih murah.

Plus, kalau Anda grow jadi 100 orang, ada Growth Plan 
di Rp 1.5M/month — still much cheaper dari consultants."

If they ask "Apa yang included?":
"Full access ke Dashboard, unlimited assessments, 
AI action plans, team support. Semuanya ada dalam package."

If they say "Perlu pikir dulu":
"Very reasonable. Tapi apa yang bikin Anda hesitate? 
[Listen]. Itu bagus, mari saya address itu..."
```

### CTA & Close (2 min)
```
"Jadi dari conversation kita, saya think Omnifit 
bisa significantly help dengan [their pain point].

Mau kami setup assessment pertama Anda? 
Kami bisa handle semuanya — Anda tinggal run, 
terus dapat dashboardnya.

Kami bisa start besok. Ada pertanyaan dulu?"

[If yes] "Excellent. Let me send Anda link untuk subscribe. 
Anda prefer monthly atau annual billing?"

[After subscription] "Bagus! Tim kami akan email Anda 
link untuk set up. Kami juga akan kasih free 
20-min consultation untuk design assessment Anda yang optimal.

Expect email dalam 2 jam. Ada yang lain sebelum saya go?"
```

```
Customer acquisition cost       < Rp 1.5M       Rp [X]     [✓/✗]
Email open rate                 20-30%          [X]%       [✓/✗]
Social reach                    300K+           [X]        [✓/✗]
Average deal size               Rp 1.5M         Rp [X]     [✓/✗]
Dashboard activation (Day 7)    70%+            [X]%       [✓/✗]
NPS (customer satisfaction)     50+             [X]        [✓/✗]
```

### Go/No-Go Decision Points

```
IF at Day 7:
✓ Trial sign-ups < 100 → ❌ NO-GO (adjust messaging/channels)
✓ Email open rate < 15% → ❌ ADJUST (revise subject lines)
✓ Trial sign-ups > 150 → ✅ SCALE UP (increase ad spend)

IF at Day 14:
✓ Conversion rate < 15% → ❌ NO-GO (revise product fit messaging)
✓ Conversion rate > 25% → ✅ EXPAND (open new channels)
✓ CAC > Rp 2.5M → ⚠️ OPTIMIZE (reduce paid ads, focus organic)

IF at Day 21:
✓ Revenue > Rp 100M → ✅ FULL STEAM (maximize campaign)
✓ Dashboard activation < 60% → ❌ INVESTIGATE (improve onboarding)
✓ NPS < 40 → ❌ PAUSE (fix product issues before scaling)

IF at Day 30:
✓ Meet all targets → ✅ CONTINUE & SCALE
✓ Meet 80%+ of targets → ✅ CONTINUE (minor adjustments)
✓ Meet <80% of targets → ⚠️ REVISE STRATEGY (root cause analysis)
```
