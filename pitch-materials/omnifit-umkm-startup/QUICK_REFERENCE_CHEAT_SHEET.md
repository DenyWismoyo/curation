## 🎁 Objection Handling Quick Reference

### "Terlalu Mahal Rp 500K"
```
✓ Frame: "Per assessment basis: Rp 500K ÷ 12 months ÷ 4 assess = Rp 10K per person per year"
✓ Compare: "Konsultan: Rp 3-5M per assessment. Omnifit: Rp 10K"
✓ Offer: "Start 3 months, then decide"
```

### "Kami Udah Punya Spreadsheet"
```
✓ Gap: "Spreadsheet tidak bisa collect 100 orang simultaneous, 
tidak ada auto-analysis, tidak ada action planning"
✓ Benefit: "Omnifit = Force execution (not just archiving data)"
✓ Social proof: "50+ UMKM switch dari spreadsheet ke Omnifit"
```

### "Tunggu Tahun Depan Dulu"
```
✓ Urgency: "Tahun depan problem yang sama. Why not start now?"
✓ Data: "Data Anda collect sekarang = baseline untuk nanti"
✓ Risk: "Missed opportunity = Hire orang salah, keep wrong people"
```

### "Privacy Issues, Employees Khawatir"
```
✓ Reassure: "Data encrypted, result hanya employee + manager lihat"
✓ Benefit: "Omnifit = Growth tool, not spy tool"
✓ Social proof: "87% UMKM employees prefer Omnifit vs traditional review"
```

### "Tidak Yakin Data Akurat"
```
✓ Explain: "Psychometric validation, adaptive questionnaire, multi-source feedback"
✓ Proof: "92% accuracy vs 70-75% traditional. 3rd party validated"
✓ Offer: "Try dengan internal team, compare dengan your intuition. Money-back if not convinced"
```
