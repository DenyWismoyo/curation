# Estimasi Biaya Pembuatan Aplikasi Omnifit

## 1) Asumsi Dasar

- Horizon perencanaan: pengembangan 6 bulan + stabilisasi 3 bulan.
- Tim inti: PM, Tech Lead, Frontend, Backend/Firebase Engineer, UI/UX, QA, AI/Prompt Specialist.
- Biaya dalam Rupiah (IDR), kisaran konservatif untuk kualitas produksi.

## 2) Estimasi CAPEX Pengembangan (Sekali Bangun)

| Komponen | Kisaran Biaya |
|---|---:|
| Discovery, riset kebutuhan, dan blueprint produk | Rp80.000.000 - Rp150.000.000 |
| UI/UX, design system, prototyping | Rp60.000.000 - Rp120.000.000 |
| Pengembangan frontend web | Rp180.000.000 - Rp320.000.000 |
| Pengembangan backend (Firebase Functions, data, integrasi) | Rp220.000.000 - Rp380.000.000 |
| Implementasi AI pipeline dan prompt governance | Rp120.000.000 - Rp250.000.000 |
| QA, UAT, hardening, dan security baseline | Rp80.000.000 - Rp180.000.000 |
| Dokumentasi, pelatihan, go-live | Rp40.000.000 - Rp90.000.000 |
| **Total CAPEX** | **Rp780.000.000 - Rp1.490.000.000** |

## 3) Estimasi OPEX Bulanan (Operasional)

| Komponen | Kisaran Biaya/Bulan |
|---|---:|
| Firebase (Auth/Firestore/Functions/Storage) | Rp8.000.000 - Rp45.000.000 |
| AI API usage (inference + context processing) | Rp10.000.000 - Rp80.000.000 |
| Monitoring, observability, backup | Rp3.000.000 - Rp15.000.000 |
| Tim maintenance (2-4 orang) | Rp45.000.000 - Rp180.000.000 |
| Support pelanggan dan operasional | Rp10.000.000 - Rp40.000.000 |
| **Total OPEX/Bulan** | **Rp76.000.000 - Rp360.000.000** |

## 4) Skenario Investasi

- **Lite (MVP-B2C fokus)**: Rp650 juta - Rp900 juta.
- **Growth (B2C + B2B siap monetisasi)**: Rp900 juta - Rp1,4 miliar.
- **Enterprise (multi-tenant, compliance, analytics lanjut)**: Rp1,4 miliar - Rp2,5 miliar.

## 5) Catatan Bisnis

- Mulai dari skenario **Growth** untuk menyeimbangkan speed-to-market dan kualitas monetisasi.
- Reviu biaya infrastruktur dan AI tiap bulan agar margin tetap sehat.
- Integrasikan target CAC, LTV, dan conversion rate saat finalisasi anggaran.
